# Weimar & Nazi Germany – Edexcel Flashcards

GCSE Edexcel History revision resources for **Weimar and Nazi Germany, 1918–1939**.

## Files

- **Weimar & Nazi Germany flashcards (Edexcel).html** — a self-contained browser flashcard app. Open it in a web browser to revise. Cards can be filtered by topic, flipped, shuffled, and navigated with the buttons or keyboard.
- **weimar_nazi_germany_edexcel.apkg** — an Anki deck containing the same revision material for use in Anki.

## HTML flashcards

No installation is required. Download the HTML file and open it in a browser.

- Click/tap a card to reveal the answer.
- Use **Prev** and **Next** to move through cards.
- Use **Shuffle** for a random order.
- Use the topic buttons to focus on a section.
- Press **Space** to flip and the **Left/Right Arrow** keys to move.

## Anki deck

Import `weimar_nazi_germany_edexcel.apkg` into Anki using **File → Import** (or the equivalent import option in your version of Anki).

## Topics covered

The flashcards cover the six sections represented in the deck:

1. Rise of the Nazis 1919–33
2. Weimar crisis 1918–23
3. Nazi control 1933–39
4. Youth and education
5. Employment and living standards
6. Stresemann and Weimar culture 1924–29

These are personal revision resources and should be used alongside the Edexcel specification, lessons and official exam materials.
